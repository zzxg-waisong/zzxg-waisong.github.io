# 榨榨鲜果 · 外卖点餐系统（静态版）

主营水果 + 现榨果汁的轻量外卖点餐系统。纯前端、零后端、零手续费、零抽成、永久免费。

## 文件说明
- `index.html`：点餐系统（顾客端 + 商家后台），全部功能内置于一个页面
- `qrcode.js`：二维码生成库（MIT，qrcode-generator）
- `收款码.png`：商家聚合收款码（顾客付款用）
- `微信二维码.png`：商家微信二维码（加好友 / 转账）

## 顾客端（免登录）
- 扫码直接进入点餐页，无需注册登录
- 分类：水果 / 现榨果汁，支持口味备注
- 购物车 → 填写称呼 / 电话 / 地址 / 预送时间段 → 提交订单
- 付款页展示聚合收款码 + 微信码（点击放大、保存到相册、长按识别）
- "我已付款"后自动整理订单文字，复制 / 发商家微信

## 商家后台
- 访问方式：点餐页底部无入口，直接访问 `#/admin`（即 链接后加 `#/admin`）
- 默认密码 `123456`，登录后在"店铺"页修改密码
- 功能：订单查看 / 高德导航（店铺→顾客）/ 复制地址 / 菜品管理 / 收款码设置 / 店铺地址设置 / 58热敏打印机（Web Serial）/ 浏览器打印 / 生成点餐二维码

## 部署
1. 把本目录全部文件上传到 Gitee 仓库（公开）
2. 仓库「服务 → Gitee Pages」开启 Pages，选择部署分支（master）
3. 生成公开链接：`https://用户名.gitee.io/仓库名/`
4. 顾客扫码访问该链接即可点餐

## 说明
- 数据保存在各自浏览器本地（localStorage），商家后台的菜品修改仅影响本机浏览器；如需更新顾客看到的菜单，修改 `index.html` 内置默认菜单后重新发布
- 付款为线下扫码聚合收款，订单文字手动发微信，无任何线上支付 / 手续费 / 抽成
